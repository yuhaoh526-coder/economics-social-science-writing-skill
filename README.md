# 经济学与社科论文写作 Skill

面向中文经济学与社会科学论文的写作辅助技能，重点支持实证结果分析与学术表达优化。目前对经济地理、区域经济和空间关联网络研究的支持较为细致。

本技能关注如何把“报告了什么结果”进一步写成“结果揭示了什么结构、过程和阶段变化”，同时保持数据准确、推断适度，以及目标期刊的段落风格。

## 适用场景

- 实证部分主要停留在数据、城市和年份的罗列，缺少分析。
- 段落内容较密，但内部逻辑和证据顺序不够清楚。
- 主语缺失、指代模糊，或比较对象不明确。
- “不能直接解释”“尚不足以确认”等限定反复出现，影响行文。
- 需要结合导师、同门或审稿人的意见修改论文。
- 需要适度压缩篇幅，同时保留关键数据和解释。

## 核心写作原则

### 从结果描述推进到分析

围绕以下路径组织实证段落：

**数据或图表观察 → 结构判断 → 空间角色或阶段变化 → 有证据支持的解释**

避免单纯罗列数值，也避免脱离结果添加宏大的机制结论。

### 保留期刊的段落风格

尊重目标期刊的篇幅、段落密度和术语习惯。对于偏好长段落的期刊，优先优化段落内部逻辑，不机械拆成多个短段落或增加小标题。

### 减少防御性写作

直接陈述证据支持的发现，减少每段结尾重复出现的免责声明。

同时保留必要的学术限定：“可能”“并不”“尚未”等词是否使用，应根据证据和语境判断，不机械删除，更不把推测改成确定结论。

### 明确主语和比较对象

写清楚哪个地区、哪类城市、哪个变量或模型发生了变化，区分区域内部差异、区域之间差距，以及相关系数、回归系数和模型拟合程度。

### 独立判断修改建议

结合原文、数据、方法和期刊风格评估修改意见，不自动接受所有建议。对先前生成的修改稿也进行同样的复核。

## 专题支持

技能中包含以下内容的写作指引：

- 空间分布与标准差椭圆
- 网络密度、可达性与小世界特征
- 节点中心性与城市功能角色
- CONCOR板块划分与板块关联
- QAP相关分析与MRQAP回归
- 统计关联、机制解释与因果推断的区分

这些专题规则仅在研究方法和数据适用时使用。

## 安装方法

下载本仓库，将 `academic-empirical-writing` 文件夹放入个人技能目录：

```text
~/.codex/skills/
```

安装后的结构应为：

```text
~/.codex/skills/
└── academic-empirical-writing/
    ├── SKILL.md
    └── agents/
        └── openai.yaml
```

仓库名称与技能名称可以不同，安装时保留技能文件夹名称。

## 使用示例

安装后，可以在请求中明确指定技能：

> 使用 $academic-empirical-writing 检查下面的实证段落，重点看防御性写作、主语指代和统计解释是否准确。先说明问题，再给出修改稿。

> 使用 $academic-empirical-writing 优化这段空间分布分析，保留数据和长段落结构，加强空间格局与阶段变化的解释。

> 使用 $academic-empirical-writing 将这一段轻度压缩，约减少一行，不删除关键数据和分析。

> 使用 $academic-empirical-writing 评估这些修改意见，结合正文和表格判断哪些应采纳，并说明理由。

为了提高修改质量，建议同时提供相关表格、图件或上下文。

## 使用边界

本技能用于辅助写作和结果解读，不替代数据分析、文献核查和作者判断。

修改时应保留原始结果、研究样本和方法；不编造系数、显著性、引文或变化趋势，也不将相关关系写成未经识别的因果效应。
